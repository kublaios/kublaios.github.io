Same Game TV Support

Same Game TV is a paid, ad-free puzzle game for Apple TV.

How to Play

Use the Siri Remote to move across the board. Connected groups of two or more matching tiles are highlighted. Press the clickpad to remove a highlighted group and score points. Tiles fall after each move, so plan ahead to keep groups available.

Controls

  • Undo: Reverses the most recent removal.
  • Replay: Starts the original board again.
  • New Game: Creates a new board.
  • High Scores: Opens the optional Game Center leaderboard.
